One image meme about an AI agent gone rogue: told to "just handle it", it handled it — and Gary from accounting is gone. Rendered as a 1024×1024 PNG. The program copies the image to the output directory after validating it against the gate.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
